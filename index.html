Tool capabilities

  • SHA-256 and MD5

    Pick the algorithm your policy names, recorded in the manifest so the policy and the file agree.

  • Baseline manifests

    Write a snapshot once, then compare every later run against the same known-good state.

  • Recursive verification

    Walk a directory at any depth and report what changed, what was added, and what vanished.

  • Readable reports

    A short, ordered result during triage: what changed, what was added, and what needs a look.

Use cases

Forensics

Establish what a host looked like before an incident, then show what moved.

Compliance

Keep a dated baseline and a verification record you can hand to an auditor.

Incident triage

Sort a noisy host into unchanged, changed, and new before you start digging.

02 / approach

The research loop.

research → tooling

Every engagement starts on the offensive side: enumerate the surface, reproduce the finding, build the smallest tool that catches it, document the result.

  1. 01

    Research phase

    Enumerate the surface, test the assumption, find what breaks.

  2. 02

    Reproduction

    Turn the finding into a repeatable case with a fixed input and a known result.

  3. 03

    Tool build

    Write the smallest tool that catches it, with no dependency you can't audit.

  4. 04

    Documentation

    Ship the README, the limits, and the reason it exists.

03 / about

About

penetration testing · offensive security

I'm a penetration tester and Informatics Engineering student working on offensive security.

Most of what I know came from breaking things in labs, CTFs, and on my own infrastructure: enumerating networks, testing web applications, and working through privilege escalation until I understood the failure itself, component by component.

That research turned into tooling. Once I kept re-solving the same problems, I started writing the tools instead: small utilities anyone can run against their own systems. Everything is open source, because a detection tool nobody can inspect is just another thing you have to trust blindly.

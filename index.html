01 About

research → tooling

I'm an Informatics Engineering student working on offensive security. Most of what I know, I learned by breaking things in labs, CTFs, and on my own infrastructure - enumerating networks, testing web applications, and working through privilege escalation until I understood not just that something failed, but why.

That research turned into tooling. Once I kept re-solving the same problems, I started writing the tools instead - small, focused utilities that anyone can run against their own systems. Everything is open source, because a detection tool nobody can inspect is just another thing you have to trust blindly.

I now work on both sides of that loop: building defensive tools and running assessment support engagements. If you have a specific workflow that needs a tool, or you want to learn offensive security properly rather than from a checklist, get in touch.

T-01

ReCheck-Integrity

Stable

A Python CLI tool for generating and verifying file and directory integrity using cryptographic hashes, with baseline manifests and recursive verification.

Use case Establish a known-good baseline, then prove whether anything on a host changed since. Useful for forensics, compliance checks, and incident response triage.

  • SHA-256 and MD5 hash algorithms
  • Baseline manifest generation
  • Recursive directory verification
  • Verification reporting
